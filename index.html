GoDaddy · WAF/CDN · Serverless orchestration

Orchestrating global WAF/CDN deployment from one product setting

Designed and built key components of GoDaddy’s WAF/CDN platform, integrating AWS and Cloudflare to turn a product setting into a working edge deployment. The event-driven, serverless architecture used Go, AWS Lambda, Step Functions, SQS, and DynamoDB Streams to coordinate provisioning, rate limiting, retries, and state.
GoDaddy · AWS · Legacy modernization · Platform engineering

Rebuilding a legacy WAF logging platform for safe testing

After leading a 1.5+ TB data recovery, I designed and built nearly the entire secure AWS dev/test platform from the ground up. The work unlocked dozens of improvements, made processing roughly 25% faster, and reduced failures from several per week to none for more than a year.
GoDaddy · Layer 7 security · WAF · API security

Designing safer Layer 7 exceptions for WAF-protected sites

Legitimate administrative traffic could trigger WAF rules, leaving customers to disable protection or request permanent exceptions. I implemented multiple path-scoped controls across Go APIs, DynamoDB, the Provisioner, Cloudflare metadata, and edge rules—keeping the rest of each site protected.
Kubernetes · Jenkins · Private cloud

Developing “as-a-Service” systems

I explored how internal infrastructure could behave like a repeatable product—from a Kubernetes-hosted Jenkins service that could deploy Jenkins to credentials-as-code and Vault-style secret services.
Distributed systems · Research engineering

Making scattered storage feel like one drive

Think private CDN meets federated filesystem: Syndicate securely combined cloud services, institutional data, caches, and personal storage while moving and caching data at block level.
CI/CD · Performance · Developer experience

Rapid debugging across any test platform

I co-designed a workflow that joined Jenkins, portable deployments, YAML tests, Valgrind, Callgrind, and DDD/GDB—letting a developer move from a failure report to active debugging in moments.
Decision systems · HPC

Simulating a running HPC environment before building it

I created a tool we called GridSim to simulate real workloads and timing against hardware that did not exist yet—revealing bottlenecks, testing scheduler policies, comparing designs, and helping avoid an estimated $400K in unnecessary cost.
Infrastructure automation · Bare metal

Turning a thumb drive into an HPC cluster

I built a system that could transform unconfigured bare-metal servers into an operational cluster—automating networking, PXE boot, diskless startup, storage, and node enrollment.
Real-time systems · GPU architecture

Turning overnight simulation into real-time imagery

An infrared sensor simulator needed to become fast enough for hardware- and software-in-the-loop testing—without giving up the scientific fidelity engineers depended on.
